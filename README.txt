KL虚幻盒子 —— Unreal Engine 项目管理器
========================================

【启动】双击 run.bat（环境已装好）。如果换了电脑或删了 .venv，先双击 install.bat。

【功能】
- 顶部可添加/删除扫描主路径，"深度"控制向下遍历几层子文件夹，点"扫描"查找 .uproject
- 每个工程卡片显示：缩略图、名称、目录大小(MB/GB)、引擎版本角标、上次打开日期
  缩略图优先级：自定义封面 > 工程目录下的图片 > Saved/AutoScreenshot.png
  上次打开日期 = Saved/AutoScreenshot.png 的修改时间
- 双击卡片：优先用注册表里对应版本的 UnrealEditor.exe 启动，找不到就走系统关联(Epic)
- 右键卡片：打开项目 / 打开目录 / 置顶项目 / 重命名 / 自定义封面 / 移除自定义封面
- 顶部右侧：按引擎版本筛选、按名称搜索
- 排序：按时间/大小/名称/版本，可切升降序，置顶项始终在最前
- 排版：「▦ 卡片」=图标网格（默认，每个工程一个圆角框，信息分行排版）；
  「☰ 列表」=横版明细（名称/版本/上次打开/大小/路径 多列，类似资源管理器）
- 大小用缓存：只有新项目、缓存超 7 天、或工程在上次统计之后动过的才会重算；
  右键「重新统计大小」可手动强制刷新
- 重命名改的是"显示名称"（存在本目录配置里），不会改动磁盘上的工程文件夹

【写入范围】
本程序只往自己所在目录写东西：config.json（设置）、covers/（自定义封面缓存）。
扫描路径、工程目录一律只读取，绝不写入或修改。

【目录结构】
KL虚幻盒子\              盒子根目录（只放启动方式与下面两个文件夹）
├─ run.bat        启动入口（双击它即可）
├─ install.bat    重装运行环境（Engine 缺失时跑一次）
├─ README.txt     本说明
├─ Engine\         ★ Python 虚拟环境（PyQt6 等依赖都在这里）
└─ UEMBox\          ★ 程序本体 + 数据（可直接整体备份）
    ├─ config.json   配置（首次扫描后自动生成）
    ├─ cache.json    项目大小等记忆缓存（自动维护）
    ├─ covers\       自定义封面缓存
    └─ app\          全部代码
        └─ UEMBox.py  主程序

代码、配置、缓存、封面都在 UEMBox\ 下；运行环境单独放 Engine\，互不干扰。
